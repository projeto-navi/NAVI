Arquitetura atual do Navi

Site estático, sem servidor: tudo roda no navegador da pessoa. Dados do local são gerados antes, a partir da planta.

Pessoa usuária

Navegador do celular ou computador. Leitor de tela (TalkBack, NVDA), voz, teclado ou toque.

QR Code / link direto

?perfil=…&origem=…&destino=… — abre o mapa já com o trajeto.

▼ acessa por HTTPS
Site navi-map.netlify.app (Netlify, plano gratuito)

1. Interface

index.html — estrutura, diálogos, ícones SVG

css/estilo.css — base e modo alto contraste

css/soft-ui.css — design Soft UI (neumorfismo)

css/mobile.css — layout de celular (até 860 px)

js/app.js — perfis, painel, mapa 2D (SVG), voz, Libras, avisos

2. Motor de rotas

js/rotas.js — grafo, Dijkstra, refino A*, instruções

js/dados.js — lugares, plantas, grafo dos corredores

js/malha.js — grade fina de distância às paredes

js/avisos.js — interdições confirmadas pela equipe

js/config.js — endereço do site e contatos do local

3. Vista 3D (sob demanda)

js/mapa3d.js — 3D e primeira pessoa

js/dados3d.js — lajes dos pisos

js/three-navi.min.js — Three.js r186

Só baixa quando a pessoa toca em 3D.

No aparelho da pessoa

localStorage

Perfil, voz, contraste, tamanho do texto, vista 2D/3D e avisos feitos no aparelho. Nenhum dado pessoal sai do aparelho.

Serviços externos

VLibras

Tradutor de Libras do Governo Federal (vlibras.gov.br)

Web Speech API

Voz (speechSynthesis) e busca falando (SpeechRecognition), do próprio navegador

Canais do local

WhatsApp, telefone e Fale Conosco, para enviar avisos

Google Fonts

Plus Jakarta Sans, DM Sans, Atkinson Hyperlegible

Preparação dos dados (feita uma vez por local, no computador da equipe)

Planta oficial

Mapa do local (no shopping: Mapa Mall)

Scripts

gen-data.js → dados.js

malha.py (OpenCV) → malha.js

lajes.py (OpenCV) → dados3d.js

Build visual

escopo.py → soft-ui.css

esbuild → three-navi.min.js

Testes

Playwright: capturas de celular e desktop, fluxo completo, primeira pessoa

Site navi-qrcode.netlify.app

Maquete que vira QR Code

js/maquete.js + js/qrcodigo.js (codificador ISO/IEC 18004 próprio). Girada para cima, a maquete vira o QR que abre o navi-map.
